Hey everyone, Suikoden II: Combat Rebalanced v1.1 is ready for public testing. I made this to give more of the roster a useful place in a party, improve underused Unites, and make several personal runes useful beyond a single action.

The changes focus on character growth, rune access, personal runes, and Unites. v1.1 also fixes stale rune-menu descriptions and adds a reviewed spelling pass across the readable game text. The combat values are the same as the previous v1.0 configuration, which remains available as the earlier release.

[SIZE=5][COLOR=#368E7B][B]What Changes[/B][/COLOR][/SIZE]
[LIST]
[*][B]Growth adjustments for 22 characters[/B] Improvements to selected stats help support their physical, magic, and utility roles as they gain levels
[*][B]Earlier head rune slots[/B] Tuta, Millie, Hai Yo, and Hoi gain access sooner
[*][B]Repeatable personal runes[/B] Trick, Groundhog, and Spider Slay can be used again in the same battle, with their damage adjusted around that repeat use
[*][B]Stronger underused Unites[/B] Fourteen named Unite families receive coefficient increases, including Swordsman, Copycat, Bow, Narcissists, and Beastmaster
[*][B]Negative Kindness fix[/B] Negative ratings retain their attack penalty instead of wrapping around to an enormous attack value
[*][B]Headquarters exit repairs[/B] Two story-stage resources receive the preload-boundary fix for the verified wall-route transition problem
[*][B]Menu and spelling cleanup[/B] Corrected rune help, all 64 verified Mercenary Soldier labels, and reviewed spelling mistakes in dialogue, descriptions, labels, and menus
[*][B]Complete change list included[/B] The second readme records every guarded vanilla-to-v1.1 edit, including original and changed bytes
[/LIST]

[SIZE=5][COLOR=#368E7B][B]Install & Play[/B][/COLOR][/SIZE]
[B]Required game: your own legally sourced, untouched USA Suikoden II BIN/CUE — SLUS-00958[/B]

[LIST]
[*]Download [B]Suikoden-II-Combat-Rebalanced-v1.1.zip[/B] and extract it
[*]Check your original BIN against the size and SHA-256 in [B]README.txt[/B]
[*]Use [URL=https://github.com/jmacd/xdelta/releases]xdelta3[/URL] to apply the patch to your original BIN and create a separate patched BIN
[*]Copy your original CUE and update its FILE entry to point to the patched BIN, following the readme
[*]Verify the patched BIN hash, restart your emulator, and open the copied CUE
[/LIST]

[B]A new game is recommended for the complete rebalance[/B]
Vanilla saves retain their own growth and rune-slot table. Patching the disc does not migrate that table or retroactively increase earned stats. Correctly migrated v0.99/v1.0 cards need no further table migration for v1.1. Use normal in-game saves when upgrading and avoid carrying emulator save states between versions.

Apply v1.1 to a clean original even if you previously used v1.0. No earlier patch is required. The ZIP contains only the patch and the two readmes. No game image, BIOS, emulator, or save is included.
